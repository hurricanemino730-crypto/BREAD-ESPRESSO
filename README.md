# 推移表コンバーター

社内システムからダウンロードした「損益計算書（月次推移）」CSV を、推移表フォーマットの Excel（.xlsx）に再集計するWebページです。

- CSV をドロップ → 推移表の項目に集計 → `.xlsx` をダウンロード
- 処理はすべてブラウザ内で完結し、ファイルは外部に送信されません
- Shift_JIS / UTF-8 どちらの CSV にも対応

## 使い方

1. `index.html` をブラウザで開く（GitHub Pages で公開している場合はそのURL）
2. 損益計算書_月次推移_〇〇.csv を選ぶ
3. 「最初の月の年」を確認（ファイル名に西暦が入っていれば自動で入ります）
4. 「集計の確認」で CSV の合計と一致していることを確認
5. 「推移表（.xlsx）をダウンロード」

## 集計ルール（初期設定）

| 推移表の項目 | CSV の勘定科目 |
|---|---|
| 売上高 | 「売上高」区分のすべての科目 |
| 売上原価 | 「売上原価」区分のすべての科目（期末棚卸高はマイナス） |
| 人件費 | 給与手当・賞与・雑給・通勤交通費・人件費振替・法定福利費・福利厚生費 など |
| 採用教育費〜雑費 | 同じ名前の勘定科目 |
| 営業外収益／営業外費用 | 各区分のすべての科目 |
| （集計しない） | 特別利益・特別損失など推移表にない区分 |

推移表に同じ名前の項目がない販管費の科目は「雑費」に入り、画面で黄色く表示されます。集計先は画面の「勘定科目の振り分け」で変更・除外でき、設定はブラウザに保存されます。

「決算整理」列は初期設定で最終月（9月）に加算します（チェックを外すと加算しません）。
